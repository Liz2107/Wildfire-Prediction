# Wildfire-Prediction

Authors: Elizabeth Cutting, Quinn Levison, Hugh MacLaughlin

Wildfires have the potential to irreparably damage important parts of many ecosystems. Recently, there has been an observed uptick in the damage caused by large and severe fires, creating a need for fire risk-mitigation tools. This paper presents a model designed to understand what drives fire risk, severity, and occurrence. By studying how lightning data impacts fire occurrence, classifying natural and human-caused fires, modeling fire probability for a given area from weather factors, and predicting associated fire severity as a function of fire size, we develop a comprehensive model that can identify risk and help understand which factors lead to potential problems that require attention.

All source code for the project is included in this repository. Please contact the contributers with any questions about the process or how to execute or run the code. 

All data was obtained through open-source datasets. Cleaned data, necessary for executing much of the program, is included in a data file. Snapshots, included per instructions, are found in the snapshots folder.
